# Tab.Master

A browser extension for managing and organizing browser tabs.

## About

Tab.Master is a browser extension developed with JavaScript, HTML and CSS.

The project provides an interface for working with browser tabs and uses the Chrome Extension API to interact with tabs and store information locally.

## Technologies

* JavaScript
* HTML5
* CSS3
* Chrome Extension API
* Chrome Storage API
* JSON

## Main Components

* `background.js` — monitors updates to browser tabs and synchronizes saved tab information.
* `manifest.json` — extension configuration and permissions.
* `popup.html` — user interface of the extension.
* `style.css` — interface styling.
* `settings.json` — project settings.
* SVG and PNG files — interface icons and visual elements.

## Storage

The extension uses browser local storage to save information about tabs.

## Purpose

The project was created as a practical exercise in JavaScript and browser extension development.
