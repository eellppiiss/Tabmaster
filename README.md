# Tab.Master

A browser extension for organizing and managing browser tabs.

## About

Tab.Master is a browser extension designed to simplify tab management and separate browser activity into two modes:

* **Work Mode** — tabs related to work or study
* **Leisure Mode** — tabs for personal activities and entertainment

The extension provides a popup interface for opening new tabs and adding them to the corresponding mode.

## Features

* Open a new browser tab
* Add tabs to Work Mode
* Add tabs to Leisure Mode
* Display saved tabs in separate sections
* Expand and collapse tab lists
* Store extension data using browser storage

## Technologies

* JavaScript
* HTML5
* CSS3
* Browser Extension API
* JSON
